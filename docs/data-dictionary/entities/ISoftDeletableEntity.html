Architectural Markers & Security Gates
Enables automatic soft deletion. When DbContext.Remove() is invoked on this entity, AuditableEntityInterceptor intercepts the operation, setting IsDeleted = true instead of issuing a SQL DELETE. Filtered out by default via EF Core query filter: QueryFilters.SoftDelete.
