[Global Scope] [Auditable] [Audit Exempt]
Persistent record of a background batch job execution. Stored in PostgreSQL with execution duration, attempt count, and error diagnostics. Architectural Tenancy Rationale: Implements (opting out of EF Core's automatic QueryFilters.Tenant) to allow platform-wide telemetry, cross-tenant operational oversight, and execution by unauthenticated system daemons (e.g. maintenance jobs with TenantId = "HOST" or "default"). Multi-tenant isolation for tenant users is strictly enforced at the application boundary via IJobManagerService. Implements to prevent recursive auditing loops, and to enforce ledger integrity.
