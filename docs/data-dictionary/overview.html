The 3-Tier Enterprise Entity Framework

BlazorEnterprise applies strict zero-trust multi-tenancy, soft deletion, and row-level auditing through a standardized three-tier inheritance model:

  • Tier 1 — Architectural Markers (IMarkerEntity): Interface gates driving EF Core query filters and interceptors (ITenantEntity, ISoftDeletableEntity, IAuditableEntity, IProjectScopedEntity).
  • Tier 2 — Reusable Base Classes: Sequential UUIDv7 primary keys (BaseEntity), audit timestamps (AuditableEntity), tenant write barriers (TenantAuditableEntity), and work item baselines (BaseTaskEntity).
